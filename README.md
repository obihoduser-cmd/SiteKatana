# О проекте

**SiteKatana** — это современный веб-сайт компании Katana, специализирующейся на продаже самурайских мечей и аксессуаров по странам СНГ. Проект предоставляет пользователям удобный интерфейс для ознакомления с ассортиментом продукции, просмотра подробных характеристик и оформления заказов.

Каждая карточка товара содержит описание изделия, основные характеристики и информацию о качестве изготовления. Для связи с компанией на сайте предусмотрен раздел с контактной информацией, включая номера телефонов и адрес электронной почты службы поддержки.

### Возможности сайта

* Просмотр каталога товаров
* Ознакомление с информацией о каждом изделии
* Удобная навигация по страницам сайта
* Возможность связи с технической поддержкой
* Адаптивный интерфейс для различных устройств

## Руководство пользователя

### Навигация

* На всех страницах сайта в верхней части расположено навигационное меню, содержащее пункты: «Главная», «Продукция», «Техническая поддержка», «Контакты».
* Переход между разделами осуществляется нажатием на соответствующий пункт меню.
* В правой части навигационной панели отображается счётчик товаров, добавленных в корзину.
* Единый стиль оформления обеспечивает удобную навигацию между страницами сайта.

### Просмотр каталога товаров

* Раздел «Продукция» содержит каталог самурайских мечей, представленных в виде карточек товаров.
* Каждая карточка включает изображение товара, его название, краткое описание и кнопку «Заказать».
* Пользователь может последовательно просматривать товары и знакомиться с их характеристиками.
* Все карточки имеют единый стиль оформления и адаптируются под размеры экрана устройства.

### Работа с корзиной

* Для добавления товара необходимо нажать кнопку «Заказать» на соответствующей карточке.
* После нажатия количество товаров в корзине автоматически увеличивается.
* Пользователь получает уведомление об успешном добавлении товара.
* Добавленная позиция учитывается в общем счётчике корзины, расположенном в навигационном меню.
* Для предотвращения повторного добавления кнопка изменяет своё состояние после нажатия.

### Раздел технической поддержки

* Страница «Техническая поддержка» содержит ответы на наиболее часто задаваемые вопросы пользователей.
* Информация представлена в виде отдельных карточек вопросов и ответов.
* Пользователь может ознакомиться с рекомендациями по использованию сайта и получить необходимую справочную информацию.
* Раздел позволяет быстро находить ответы на распространённые вопросы без обращения к администрации сайта.

### Контактная информация

* Раздел «Контакты» содержит сведения о компании и её руководителе.
* На странице отображаются адрес организации, номер телефона и адрес электронной почты.
* Дополнительно представлена карточка генерального директора компании с фотографией и контактной информацией.
* Для удобства пользователей встроена интерактивная карта местоположения организации.

### Главная страница

* Главная страница содержит информацию о компании и её деятельности.
* Пользователю доступны сведения о преимуществах компании и предлагаемых товарах.
* На странице размещён информационный баннер и блок преимуществ, представленный в виде карточек.
* Все элементы страницы адаптируются под различные размеры экранов и обеспечивают удобное восприятие информации.

### Адаптивность интерфейса

* Сайт корректно отображается на персональных компьютерах, планшетах и мобильных устройствах.
* При изменении размеров окна браузера элементы интерфейса автоматически перестраиваются.
* Карточки товаров и информационные блоки сохраняют читаемость и удобство использования на различных разрешениях экрана.
* Адаптивная вёрстка обеспечивает комфортную работу пользователя независимо от используемого устройства.
